# ESG Sustainability Dashboard

A dashboard for reviewing sustainability and ESG records.

## Features

- Upload CSV files
- Fuel, Electricity, Travel categories
- Suspicious record detection
- Approval workflow
- Search and filters
- Dashboard metrics

## Tech Stack

Frontend:
- React
- Vite
- Axios

Backend:
- Django
- Django REST Framework
- SQLite

## Run Project

Frontend:
npm run dev

Backend:
python manage.py runserver
